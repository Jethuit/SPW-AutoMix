# 首轮验证计划

本轮要回答两个独立问题：SPW 1.19.3 能否按插件提供的计划执行，并保持原队列与设备状态？在完全掌握输入和时间轴时，参考渲染器能否把两首歌混得自然？以下实验均待执行。

## 宿主计划替换

用隔离测试配置、两首可自由使用的本地 WAV 和固定的 A → B 播放顺序。A、B 使用可单独识别的节拍与频率标记，B 同时包含低频和中高频。所有对照沿用同一设备、主音量、采样率与宿主效果设置。记录宿主版本、输出模式、计划参数、输出捕获方式及对应的队列事件。

| 顺序 | 操作 | 观察和判定 |
| --- | --- | --- |
| 1 | 原生 Morvanium 播放一次，再只读观察同一曲对 | 核对预览的 B 和实际提交的 B，标出准备、起混、提交及结束。确认采集同时包含两轨，建立原生对照 |
| 2 | 只对该曲对改变 B 的入点一个小节 | 根据 B 的源标记测量进入位置，核对 A 的源位置和队列推进次数。只有设置值变化、输出没有变化时记为未通过 |
| 3 | 保持入点，分别渲染原增益、仅 B 静音、仅 B 低频衰减三次 | 静音时 A 的标记仍在。低频处理时 B 的低频衰减，B 的高频和 A 的标记保留。由此区分真实单轨控制与主总线上的变化 |
| 4 | 分别在准备期间和重叠期间插播、拖动、暂停恢复、手动切歌和停用 | 被取消的 B 不再进入；暂停冻结播放进度，恢复后不重复触发；每次有效交接只提交一次。停用后无残音或额外设备占用 |

先在有可靠输出捕获的共享模式验证。独占及其他后端单独记结果；无法捕获时标记未测。若计划替换失败，记录失败位置是目标注册、计划构造、执行器拒绝还是输出未变化，以决定是否改试自定义音源。单轨 EQ 验证失败时单列该项，保留已经实测的能力。

## 离线混音与试听

最小原型接受两个 WAV、手工标注的小节强拍、A 退出区起点、B 入点、过渡小节数及两轨增益/EQ 曲线。导出保留前后乐句的 WAV、实际采用的计划及测量结果。用已知拍网先检查首拍、末拍与累计漂移，再用有主唱、强底鼓及速度不稳定的真实曲对试听。

| 素材与操作 | 判定重点 |
| --- | --- |
| 120 BPM、4/4、原速，选 4 小节 | 理论重叠为 8 秒。比较两轨每个标记在输出时间轴上的位置，分别验证静音及低频交换 |
| 同一稳定节奏，不同源 BPM，开启或关闭匹配 | 开启时检查首末拍误差、音高和瞬态；关闭时各轨保持原速。分别记录首拍偏移和后续漂移，避免把伸缩预热延迟误判为 BPM 错误 |
| 两首歌的底鼓都强，或两端都有主唱 | 随机化顺序、匹配整体播放响度，对比手动计划、短淡化和原生过渡。注明哪一拍低频变薄、哪一句被截断；有可比母带和过渡时加入 Spotify 对照 |
| 连续专辑曲或弱拍现场录音 | 保留自然衔接作为对照，听辨尾音截断、重复起音及不必要的静默；这些样例随后用于验证自动回退 |

每个曲对记录源区间、模式、计划版本、拍差、真峰值、响度变化及带时间点的试听意见。保留失败样例供下轮复听。通过合成信号检查后，再依据真实素材决定是否推进自动选点。
