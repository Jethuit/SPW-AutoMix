# SPW AutoMix 产品需求

SPW AutoMix 是面向 Salt Player for Windows 创意工坊的独立插件。用户按原有方式播放本地歌单时，插件应能为相邻两首歌选择自然的交接位置；用户也可以试听、修改并保存这一次交接。混音质量以实际听感评判，尤其关注第一记底鼓能否接稳、一句主唱能否唱完，以及交接前后的响度是否自然。

当前阶段已完成宿主静态调研。实现路线及证据见[技术设计](AUTOMIX_DESIGN.md)，下一步的实验和判定方法见[首轮验证计划](FIRST_VALIDATION.md)。

## 自动模式

1. **后台分析本地文件。** 保存 BPM、逐拍位置、小节强拍、拍号估计及节奏稳定性；估计调性及 Camelot 表示、结构边界、静音、能量、人声活动和低频分布。每类估计记录置信度。第一版可以只定位段落边界，后续再细分前奏、主歌、副歌、间奏和尾奏。复用已有分析，文件内容或相关分析设置变化后重新计算。
2. **为有顺序的曲对制定计划。** 在 A 的退出区域与 B 的进入区域比较候选乐句，综合拍相位、和声、能量、低频及主唱冲突。计划包含两个源位置、重叠长度、速度及每轨自动化曲线。记录选择及放弃其他候选的理由，供调试和人工修改。
3. **按歌曲条件执行。** 稳定且兼容的曲对可以沿小节长混；两轨底鼓冲突时交换低频；人声相撞时先改切点或缩短重叠。弱拍、速度漂移或变速损伤音质时保留原速。分析失败、未及时预加载或没有合适窗口时，选短淡化或交还宿主自然衔接。

## 手动模式与预设

| 参数 | 用户可选内容 | 听感与执行约束 |
| --- | --- | --- |
| 长度 | 2、4、8 小节，后续考虑 16 小节和自定义长度 | 按实际拍号和局部网格计算 |
| 音量 | 流畅淡入/淡出、重叠、淡入淡出、切入淡出、淡入切出 | 每轨独立增益与插值，考虑响度差及峰值余量 |
| EQ | 中间、末尾或开头低音切换，三频段淡入淡出，快速低音切出 | 低、中、高频可逐轨自动化 |
| 滤波 | 无、低通切出、低通切入、低通切入及切出、低通切入与高通切出 | 平滑移动截止频率 |
| 效果 | 无、混响中段淡出、混响末尾切出、混响末尾淡出、半拍回声末尾切出 | 效果尾音自然衰减 |
| 循环 | 无、1/2/4/8 拍循环 | 跟随拍网，处理循环接缝 |
| 节拍匹配 | 开或关 | 开启时限制变速范围并保护音高；关闭时维持原速 |

预设保存上述参数组合，支持自动推荐、手动选择及另存。双轨编辑器显示歌曲名、BPM、调性、波形、实际重叠区与自动化曲线。用户可拖动起止点、切换预设并试听；改参数应复用分析结果。保存 A → B 的调整只影响该方向的曲对。先验证算法和 DSP，再开发完整编辑器。

## 播放与性能

SPW 应继续正确处理顺序与随机播放、插播、上下首、暂停恢复、拖动、进度与元数据更新、音量及设备变更。切歌前预加载；队列变化及时作废旧计划。宿主过渡与插件计划只能执行一次。启用、停用、卸载和设备重建后应释放相应音频资源、工作线程和内存缓存。分别记录 WASAPI 共享、独占及其他可用后端的兼容范围。

渲染优先使用高质量浮点 PCM，避免重复编码。参数变化应平滑，处理伸缩延迟、分频重组、峰值和效果尾音。分析、文件读写及可能阻塞的工作在音频回调外执行。分析、规划、渲染和界面分开，以便用同一曲对定位问题。

## 产品验收

- 两首真实重叠，改变任一轨的增益或 EQ 能单独听出和测出。匹配节拍后，从第一个强拍到交接结束均无明显错位。
- 对不同风格的曲对，出入点符合乐句或段落，策略随素材改变。适合长混的过渡无明显响度跳变、削波、爆音或持续抢拍；不适合的曲对能安全回退。
- 重播复用有效缓存，修改文件后分析更新。手动配置可重开、可试听，结果与正常播放中的同一计划一致。
- 过渡前、中、后操作播放器，队列、进度和输出都正确；没有双重输出或停用后仍在播放的音频。
- 使用同一曲对做响度匹配试听，保留与 Morvanium、普通衔接及可获得的 Spotify 混音版本的对照记录。记录具体失误的位置和原因，作为下一轮迭代依据。
