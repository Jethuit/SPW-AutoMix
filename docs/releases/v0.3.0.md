# SPW AutoMix v0.3.0

v0.3.0 的 Windows x64 离线安装包约 **7.5 MiB**，比 v0.2.0 缩小约 **83%**。

## 更新内容

- **精简 FFmpeg**。支持离线分析和试听常见的 FLAC、MP3、AAC/M4A、WAV、Wave64、ALAC、Ogg/Opus、APE 和 DSD（DSF、DFF）音频。
- **转场撤销和重做**。波形下方可撤销或重做切点、交接点、预设和参数修改。每次拖动算一步，历史按曲对分别记录。删除保存方案时会保留未保存的草稿。
- **自动检查更新**。「关于」显示当前版本、上次成功检查时间和更新状态。可关闭自动检查，或随时手动检查。发现新版时，右上角会显示提示点。
- **界面调整**。返回按钮使用 Salt UI 桌面组件，撤销、重做和刷新使用 Google Material Symbols。波形和右侧列表之间的间距缩到 20 dp。
- **稳定性修复**。修复从托盘恢复窗口时可能发生的崩溃、拖动中断后撤销按钮卡住的问题，并改进取消试听时的进程清理。

## 安装

在 SPW「创意工坊」导入 `SPW-AutoMix-v0.3.0.spmod`，授予曲库读取和类变换权限，然后从左侧栏打开 **AutoMix**。要让插件接管实际切歌，请在 SPW 的播放设置中开启「Morvanium智能过渡」。

`SPW-AutoMix-v0.3.0-FFmpeg-source.zip` 提供内置解码器对应的源码和构建参数。
