## SPW AutoMix v0.2.0

标准版安装包 `SPW-AutoMix-v0.2.0.spmod` 内置 FFmpeg，导入后即可离线分析、编辑和试听。兼容性已在 Windows x64 上的 **SPW 1.19.3** 验证。

### 界面与动效升级

- **全面适配 SaltUI 3.1 与 SPW 原生风格**：重构页面标题栏、卡片与控件层级，全面支持亮色 / 暗色以及亚克力、云母、云母 Alt 和壁纸窗口材质。
- **启用 SaltUI Glass（液态玻璃）效果**：参数菜单、歌单弹窗以及双轨波形上的悬浮试听按钮与小节数胶囊均启用液态玻璃质感。
- **右侧播放列表改版**：改用分段控件切换「队列 / 歌单 / 已保存 / 自选」，曲目采用轻卡片配卡间连线过渡节点，调序箭头改为悬停显现，首次打开队列自动定位到当前播放曲目附近。
- **新增页面进出场动效与跨插件导航交接**：接入与 SPW 一致的弹簧切入 / 返回动画，离场时自动关闭弹窗并停止试听，与「听歌统计」等页面互切更顺滑；新增会话级曲库、封面与波形缓存并延后切入期状态提交，显著提升切入流畅度。
- **关于与手动检查更新**：右上角新增「关于」入口，可查看当前版本、打开发布页并手动检查 GitHub 正式版更新，发现新版本时显示提示点；「保存」按钮移至波形图下方图例右侧。

### 音频过渡与实播增强

- **实播高通滤波**：在 SPW 1.19.3 上支持将高通切入、切出以及双轨高通 / 低通组合用于实际切歌（需开启 SPW「智能过渡」）；三频段均衡与噪音尾段继续用于编辑器试听。
- **更多预设与参数选项**：新增「上升」「混音」「渐融」「涌升」和「无过渡效果」预设；音量新增「淡入快出」，均衡器新增多档低音切出 / 淡出，滤波支持双轨高通、混合滤波及噪音尾段淡出。

### 交互修复与优化

- 参数下拉菜单增加高度上限、固定标题与滚动条，支持按窗口空间自适应弹出方向，以及键盘导航与悬停曲线预览同步。
- 修复歌单存在重复曲目时的列表键值与高亮错位、总览条点击居中与磁吸、预设与自动推荐状态切换、交接点竖线拖动适配以及窄窗口下的排版溢出问题。

### 安装与使用

在 SPW「创意工坊」导入 `SPW-AutoMix-v0.2.0.spmod`，授予**曲库读取**和**类变换**权限并启用，然后在 SPW 播放设置中开启**智能过渡**即可接管实际切歌。左侧导航栏提供 **AutoMix** 入口。
