# SPW AutoMix

AutoMix 是 Salt Player for Windows 的歌曲转场插件。它会分析本地歌曲，建议上一首从哪里淡出、下一首从哪里进入。你可以直接用自动推荐，也可以在双轨波形上调整过渡并试听。

**[下载 v0.1.0 安装包（.spmod）](https://github.com/Jethuit/SPW-AutoMix/releases/download/v0.1.0/SPW-AutoMix-v0.1.0.spmod)** · [其他版本](https://github.com/Jethuit/SPW-AutoMix/releases)

适用 Windows x64，已在 SPW 1.19.3 上检查兼容性。安装包内置 FFmpeg，音频分析和试听可离线运行。

## 安装

1. 在 SPW 的「创意工坊」导入下载的 `.spmod` 文件。
2. 按提示授予「曲库读取」和「类变换」权限，再启用插件。前者用于读取本地歌曲和歌单，后者用于让 SPW 在切歌时采用 AutoMix 的方案。
3. 从 SPW 左侧栏打开「AutoMix」。也可以在插件配置页点击「打开 AutoMix」。

## 第一次试听转场

1. 在右侧队列或歌单中，点击两首歌之间的转场按钮。如果正在播放，也可以点「当前转场」定位到当前歌曲和下一首。
2. 选「自动」，点击两条波形中间的播放按钮，先听一次推荐的衔接。波形上方和下方分别显示退出曲、进入曲，并标出拍点、速度（BPM）和可识别的调性。
3. 想调整听感，可以拖动波形改变交接位置，或调整过渡长度、音量、低音、滤波和回声。试听会匹配两首歌的响度。满意后点右上角「保存」，把设置留给这对歌曲。

**想在正常切歌时用上 AutoMix？** 在 SPW 播放设置里开启「智能过渡」。已保存的曲对方案优先，其他曲对可使用已准备好的自动推荐。只使用自动推荐时可以省去逐对保存。

## 扫描和整理歌单

右侧列表支持双击播放和拖动排序。在「歌单」里选中一张歌单，再打开「生成混音」，可以选择以下操作。

| 选项 | 会发生什么 |
| --- | --- |
| 仅扫描 | 分析歌曲并缓存结果，方便之后查看 BPM、调性和编排。 |
| 挑歌并新建 | 选出适合衔接的歌曲，按推荐顺序另存为新歌单。 |
| 全单重排并新建 | 保留全部歌曲，按推荐顺序另存为新歌单。 |

首次完整分析支持最多 15 分钟的音频。扫描时会跳过超限曲目，后续可复用有效的分析缓存。
