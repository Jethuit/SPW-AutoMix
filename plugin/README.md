# SPW AutoMix 创意工坊插件

在 SPW 1.19.3 的创意工坊中导入 `SPW-AutoMix-v0.1.0-dev.18.spmod`，授予曲库读取与类变换权限并启用；播放设置中打开智能过渡后即可生效。启用后会在 SPW 左侧导航栏注入原生 **AutoMix** 入口，也可在插件配置页点击 **打开 AutoMix** 进入。

## 主要改进（v0.1.0-dev.18）

- 调序使用宿主队列项的真实索引，收到宿主确认后才开放下一次移动。「当前转场」会按播放模式选择下一首。
- 刷新列表和跳到当前转场是两个操作。切换曲对会保留本次插件运行中的草稿，保存和删除状态随实际结果更新。
- 试听和实际切歌共用有效重叠区间。点波形可以从所选位置开始试听。
- 「沿用 SPW」将该曲对的转场交给播放器。旧版已保存的瞬切设置保持原样。
- 修复不足 2 秒音频的响度分析，自动变速要求两轨都有可信拍网。

### 历史更新（v0.1.0-dev.17）

1. **右侧队列与 SPW 播放列表 1:1 实时同步**：
   - 将队列顺序改为直接按 SPW 队列弹窗的 `0..N-1`（`normalQueue`）原始索引排列，并新增轻量队列指纹实时监听，SPW 内切歌、添加或修改队列后右侧面板会立即自动同步更新，`当前` 标签与 `current / total` 计数准确高亮正在播放曲目。

## 依赖与构建

- **运行环境**：`py -3`、含 `rubberband` 滤镜的 FFmpeg，以及 NumPy、SciPy（分析缓存按键存放在插件配置目录下的 `analysis/`）。
- **开发构建**：从仓库根目录运行 `py -3 tools/build_plugin.py`，产物输出至 `build/libs/SPW-AutoMix-v0.1.0-dev.18.spmod`。
