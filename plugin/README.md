# SPW AutoMix 创意工坊插件

在 Windows x64 上，将 AutoMix 安装包导入 SPW 创意工坊，授予曲库读取与类变换权限并启用。播放设置中开启智能过渡后，AutoMix 可以接管切歌。左侧导航栏的 **AutoMix** 和插件配置页的 **打开 AutoMix** 都能进入编辑器。

## 安装包

AutoMix 使用 Kotlin 进行音频分析、波形生成、自动选点、歌单排序和试听渲染。歌单通过 SPW 的数据库读取接口加载。离线版随包提供 FFmpeg，负责把源文件解码为 PCM。

离线包内置面向本地音频解码的精简 FFmpeg。开发轻量版从 SPW 进程的 `PATH` 查找 FFmpeg，也可设置 `AUTOMIX_FFMPEG` 指向可执行文件。修改环境变量后重启 SPW。 [v0.3.0 更新说明](../docs/releases/v0.3.0.md)

编辑器试听以 −14 LUFS 为目标匹配双轨响度，并预留峰值余量。首次完整分析支持最多 15 分钟的音频。扫描遇到超长曲目时会跳过该曲，有效的旧分析缓存仍可复用。

「自动」会在出入点附近比较多组强拍，按重叠段的响度差、低频重叠和局部结构变化选点。下一首前奏明显进入持续的主段时，优先在该段附近交接。可在编辑器的「分析依据」查看评分及识别出的段落时间。开启 SPW 智能过渡后，插件为当前队列的下一首在后台准备同一原速方案，实际切歌时会自动采用。手动保存的设置优先，推荐尚未就绪或错过切点时会回退到原速匹配。

在右侧「歌单」打开选择器，搜索或切换源歌单。点击「生成混音」后可选「挑歌并新建」「全单重排并新建」或「仅扫描」。挑歌时优先选择拍网可靠、原速下能对齐 BPM 的曲目，并用调性、响度和低频重叠决定衔接顺序。全单重排保留每首歌，并显示较弱的衔接数。仅扫描会将 BPM、调性等分析结果存入缓存，供之后编排复用。扫描进度与取消操作显示在原按钮旁，新生成的歌单另存到 SPW 曲库。

编辑器继承宿主的亚克力、云母、云母 Alt 和壁纸背景。材质模式下，底层宿主页面保持组合状态，并在 AutoMix 打开时隐藏。经典主题与材质接入不可用时使用实色页面，参数菜单始终使用不透明的主题色。

AutoMix 在后台通过宿主的类、方法签名和字节码调用位置识别过渡引擎、队列、导航、侧栏和主题。目标缺失或存在歧义时，该项接入会停用。1.19.0 的歌单仅可浏览和选择曲对，队列排序和歌单排序是独立能力。界面发现方式参考 SPW Listen Stats，其中部分结构规则源自 SPW-Lyrics，两份 MIT 许可均随包提供。

打开曲对时，AutoMix 会按本地音频估计两首歌的主要调性。在 BPM 旁显示标准调名和 Camelot 编号，例子是 `C♯m · 12A`。置信度不足时显示「调性未知」。

右侧队列和歌单左侧显示封面，中间显示歌名与艺人，右侧显示 BPM、调号和时长。封面从 SPW 曲库读取，缺少封面时显示占位图。双轨波形旁显示所选转场两首歌的 BPM，歌曲行数据会复用已有的本地分析缓存。

点击右上角「当前转场」会切到队列并滚动到当前歌曲。有可编辑的下一首时，同时打开两首歌之间的过渡。

双击右侧队列的歌曲可直接跳到队列里的该条目。双击歌单里的歌曲会从该曲开始播放这张歌单。单击歌曲可选择相邻转场。

按住歌曲左侧拖动手柄，移到列表上缘或下缘可持续自动滚动，松开后将歌曲移动到目标位置。

音量、均衡器、滤波、效果和过渡长度使用浮动选项菜单。悬停选项时，波形会预览对应的曲线或重叠范围。移开后恢复当前值，点击后应用。音量的「流畅」使用两端平缓的 S 形淡入淡出曲线。当前值带勾选。按 Esc 或点击菜单外可关闭。

「效果」菜单提供混响中段淡出、混响末尾切出、混响末尾淡出和无效果。三种混响可在编辑器试听。已保存的半拍回声仍可读取和播放。

绿色短刻度标记各轨的小节首拍，灰色圆点标记普通拍点。开启「拍点磁吸」后，拖动切点接近目标时优先对齐两轨的小节首拍，其次选普通拍点。强拍的吸附位移上限为 45 毫秒，普通拍为 18 毫秒。自动推荐也会比较重叠区内的不同位置，并检查各候选长度的原速漂移。

### 开发版高通实播（v0.1.1-dev.3）

识别到支持的 SPW 滤波链时，高通切入、切出和双轨组合可用于实际切歌（在返回后就地改写宿主分配的 `BASS_BFX_BQF` 参数缓冲，以兼容 SPW 1.19.3 Workshop 方法 Hook 的返回值机制）。开启 SPW「智能过渡」并保存曲对设置，即可应用高通。混合滤波在各轨分别运行高通或低通。宿主接入不可用时，高通继续标为「仅试听」。三频段均衡与噪音尾段继续用于编辑器试听。

### 开发版新增预设（v0.1.1-dev.1）

- 新增「上升」「混音」「渐融」「涌升」和「无过渡效果」。选择「无过渡效果」并保存后，上一首播到曲尾，下一首从头进入。
- 音量新增「淡入快出」，均衡器新增不同速度的低音切出和淡出。滤波菜单提供双轨高通、低通与高通组合，以及噪音尾段淡出。
- 三频段均衡、高通和噪音标有「仅试听」。这些效果会在编辑器试听时应用，正常切歌会应用同一方案中的音量、低音均衡、低通等受支持的设置。

## 依赖与构建

- 单曲分析缓存存放在插件配置目录下的 `analysis/`。
- **离线版构建**运行 `py -3 tools/build_plugin.py`。构建会校验固定版本的 FFmpeg，下载缓存放在 `build/runtime-downloads/`。
- **轻量版构建**运行 `py -3 tools/build_plugin.py --system-runtime`。轻量版使用本机 FFmpeg。两种安装包都输出到 `build/libs/`，各自使用独立的版本号。
